# D-16: tile size (delegated to Dominus, 2026-09-30)

**Question.** The requirements fix a tile grid (ENV-11) and the character size (D-04: 32x48 px) but not the tile size. US-023 needs it.

| Option | For | Against |
|---|---|---|
| **32x32 px (chosen)** | Characters are exactly one tile wide; 15 x 8.4 tiles fit the 480x270 virtual screen, enough to see the surroundings | Fewer tiles on screen than with 16 px |
| 16x16 px | More world on screen, classic look | A 32-px-wide character straddles two tiles; tile art gets very small |
| 48x48 px | Big, detailed tiles | Only 10 x 5.6 tiles visible: too cramped |

**Decision.** 32x32 px. The owner may override; changing tile size later means redrawing tiles only, not code.
