| Q | Question | Owner answer |
|---|---|---|
| Q1 | Which M9 | The graph editor (US-170..175); M9a, M9b, M9c are done and tagged |
| Q2 | Dirty working tree | Work in a worktree; leave the other session's files alone (moot once M8d and M8e finished and the tree was clean) |

| Q19 | Undo scope | Shared with the map edits (one History) |

| Q21 | Test cadence | Per story its own cases alone; one full verify at X-M9 |
| Q22 | Finish | Merge qa into main, tag m9-done, CI green, one rerun then stop |
