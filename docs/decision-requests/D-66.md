# D-66 US-205 design decisions (camps and resources)

Status: **Decided by Dominus (delegated)**, 2026-10-09, under D-41. The owner may override any line later; if one changes, US-205 is reopened. Design: docs/plans/M12-world-editing-design.md section 9.

| Q | Question | Options considered (recommended first) | Decision and reason |
|---|---|---|---|
| Q1 | Kinds of camp | `player` and `rival` camps; one kind with a clan id | **`player` and `rival`.** There is one player camp (the hero's start) and any number of rival camps; a rival's `name` is its clan. A second player camp is refused ("move it instead"). |
| Q2 | Placement rules | Reuse the generator's site check; invent a new one | **The generator's check** (`Region::goodSite`: water and food within reach and a walk to both), plus: walkable and not a cave mouth, at least 8 tiles from any other camp, a known kind. Each refusal says why. **Anyway** places a camp where the site check fails; it is saved as `forced` and is not a conflict. |
| Q3 | Rivals at the placed camps | Rival clans start at placed camps and the generator fills up to two; only placed camps | **Placed first, then generated.** The first clans live at the placed rival camps (named and sized as the entry says, property `people`); the generator adds clans until there are two, away from them. After the start a clan still moves with the seasons as rivals always did (US-042). |
| Q4 | The player camp | Move the start; leave the start and mark the camp | **Move the start.** `Region::setStart` at the camp; taking the camp off gives the generator start back. The carved start area (pond, wood) is not carved again: the site check is what keeps a start fair. |
| Q5 | Resource amounts | An `amount` property of a resource entry: where the seed has a spot it sets how many can be taken; where it has none it puts a new spot | **As listed.** `Region::harvest` gives one unit at a time for flint and wood spots of several (berries and herds keep their rules; a herd's amount is its animals); what is left is kept in the run save (optional `amounts` in `region.json`, version unchanged). |
| Q6 | Hiding a seed spot | A new kind of entry; the tombstone of US-204 | **The tombstone of US-204.** Take away hides the spot; `Region::hideResource` removes it from the chunk, so rivals' site scores and the site check see it gone. |
| Q7 | Where the amounts reach the game | Now; from US-207 | **From US-207, as D-63 and D-65.** The region made from the world file holds the camps, spots and amounts (and rival clans start at the placed camps through `Rivals`); the level the running game draws still makes one plant for a spot. Play here wires the file into a run. |
| Q8 | Left out | Resource counts per kind in a panel; start store of a camp; a reachability warning for camps | **Left out** (not in the acceptance criteria): a new story if wanted. |
