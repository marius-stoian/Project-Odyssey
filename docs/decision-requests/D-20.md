# D-20: Which level do the game and the tests use? (Decided by Dominus, delegated)

**Asked:** 2026-09-30 by Mraw during S-US-125. **Status:** Decided by Dominus (delegated). The owner may override.

**Question.** The owner edited `assets/levels/valley.json` in the Editor and saved it (the path across the valley, and more). The accepted tests (US-024 walk to the rock, US-029 spear throws, US-122 levels, US-123/124 editor) need the original demo layout: the rock east of the start, the two straw targets, the pond. What should the game and the tests use?

| Option | What happens |
|---|---|
| **A. The owner's valley is the game's level; the original demo becomes `demo.json`, which every test plays (chosen)** | The owner keeps building his valley; the tests keep their fixed ground truth and never change when he edits |
| B. Restore valley.json; the owner works on a copy | The owner's work moves out of the default level; he must pass `--level` to play it |
| C. Rewrite the tests for the owner's valley | Tests break again every time he edits |

**Choice: A.** The owner's level is his content and stays the default (`odysseus.exe` opens it); tests need a level that never changes, so they use `assets/levels/demo.json` (the demo exactly as it was built, checked against the old code in `US-122 Load`). Level backups (`*.bak1..3`) stay on the owner's disk and are not committed.
