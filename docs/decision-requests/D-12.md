## What to do (about 30-60 minutes, mostly waiting)

Open **PowerShell** (not as administrator; Windows will ask for approval where needed) and run these one at a time.

1. **Visual Studio Community 2026 with C++** (free; the compiler, debugger, CMake, Ninja and AddressSanitizer):
   ```powershell
   winget install --id Microsoft.VisualStudio.Community -e --override "--wait --passive --add Microsoft.VisualStudio.Workload.NativeDesktop --includeRecommended --add Microsoft.VisualStudio.Component.VC.ASAN"
   ```
2. **CMake** (so builds also work from any terminal):
   ```powershell
   winget install --id Kitware.CMake -e
   ```
3. **vcpkg** (downloads SDL3 and the other libraries for us):
   ```powershell
   git clone https://github.com/microsoft/vcpkg C:\dev\vcpkg
   C:\dev\vcpkg\bootstrap-vcpkg.bat -disableMetrics
   [Environment]::SetEnvironmentVariable("VCPKG_ROOT", "C:\dev\vcpkg", "User")
   ```
4. **GitHub** (needed for US-002; you can do this later if you only want the .exe first, see CI-002):
   - If you have no GitHub account, create one at github.com yourself.
   - Then:
   ```powershell
   winget install --id GitHub.cli -e
   gh auth login
   ```
   Choose GitHub.com, HTTPS, and log in with the browser.
5. **Restart** your terminal and Claude Code (so the new PATH and VCPKG_ROOT are picked up).
