# D-65 US-204 design decisions (things, people and places in the region)

Status: **Decided by Dominus (delegated)**, 2026-10-09, under D-41. The owner may override any line later; if one changes, US-204 is reopened. Design: docs/plans/M12-world-editing-design.md section 8.

| Q | Question | Options considered (recommended first) | Decision and reason |
|---|---|---|---|
| Q1 | What a "thing" is | One group for plants, objects and animals, resolved from the catalogs when the level is made; separate groups for plants, objects and animals | **One group, `things`.** Objects already ride on the plant machinery (CI-008), so a fire pit is a plant kind flagged `object`; an animal is a character kind. The palette lists them together and `levelFromRegion` tries the plant catalog first, then the character kinds. |
| Q2 | Properties that win over the kind | Any key; a short list per group, checked when set and when the file loads | **A short list per group.** Person: `hp`, `swordDamage`, `family`, `attitude`, `tags`. Thing: `hp` (an animal) and `<interaction>.duration` / `<interaction>.delay` in whole seconds (a plant; these become the same per-thing overrides the Editor already writes, US-173). Place: `tags`. Anything else is refused in the tool and is a DataError naming file and field when it is in a hand-edited file. Camps and resources have none until US-205. |
| Q3 | Names | Free text; a name that is also a word | **Free text for the owner, a word for the level.** A place needs a name, unique ignoring letters' case, without `:` `,` `;` (the marker and goal syntax), at most 40 letters. A person's name is optional and at most 18 letters (the Level's limit). The level the game plays names the place with the quest word of it ("Red Cliff" becomes `red-cliff`), as level files do, so a quest marker `place:Red Cliff` finds it. |
| Q4 | Ids | A counter in the file; the largest id in use plus one | **Largest in use plus one, per group** (`t-0001` things, `p-0001` people, `l-0001` places). An id is never changed by a move, a save, a load or a regeneration of the land. The level's own numeric ids are made in group order and file order, so one file always gives the same level. |
| Q5 | Move and take away | Drag to move, box select, duplicate; click to pick and click to drop | **Click to pick, click an empty tile to drop** (Move); **Take away** removes the owner's own entry under the click, or hides the seed's own wood, berries, flint or herd there with a tombstone. Drag, duplicate and box select are in design section 8 but not in the acceptance criteria, so they are left out (scope rule); a new story if wanted. |
| Q6 | Conflicts after regeneration (moved here from D-63 Q10) | A list with a choice for each line; two buttons for all; the Move and Take away tools by hand | **Buttons for all, tools for one.** **Fix: move** puts every entry the land no longer suits on the nearest tile (searching 30 tiles out, in rings) where it can stand; **Fix: drop** takes them off. For a single entry the owner uses Move or Take away. Keeping is doing nothing: the entry stays, the list still names it, and the game skips an entry it cannot place and says so. Each button is one step of Undo. |
| Q7 | Where the game reads the world file | Now; from US-207 | **From US-207, as D-63 decided.** `levelFromRegion` takes the edits and is tested ("appear in the game" is proven on the level the game plays from); Play here (US-207) wires the file into a run. |
| Q8 | Pickers | New catalogs; reuse | **Two new catalogs and the old ones extended.** `people` (the level's characters and the region's people) for `graph.quest.giver` and `graph.header.who`; `goals` (`goto <place>`, `talk <person>`) for `graph.step.goal`; `places` and `markers` (`place:`, `npc:`) also list the region's places and people. The quest check accepts the region's names too. |
| Q9 | Ordering the quest check catalog | Refresh on every placement; on data reload | **On data reload.** The pickers read the live list every time they open; the checks of the graph editor read the catalog made at the last reload (F5 or Save). |
