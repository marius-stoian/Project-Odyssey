# D-58 Editor help and live data (M10b)

Status: **Decided (owner, 2026-10-05)**, 11 questions in three chat rounds when the owner asked for "tooltips in the Game Editor, auto-suggestions on every field, and Editor changes reflected in the Game after save". Brief: docs/plans/M10b-editor-help-live-data-brief.md. Builds as epic E29, stories US-300..US-305.

| Q | Question | Options offered (recommended first) | Owner answer |
|---|---|---|---|
| Q1 | Where does this go in the plan | New milestone M9d built now in a worktree; insert before M10 continues; queue after M10 | **Queue after M10** (milestone M10b, after X-M10, before K-M11) |
| Q2 | What a field tooltip shows | Purpose + range + example; purpose only; long help + guide link | **Purpose + range + example** |
| Q3 | How auto-suggestions work | Dropdown list; inline ghost text; both | **Dropdown list** (Up/Down, Tab/Enter, Esc) |

| Q5 | Which editors "every field" covers | All three; Level only; Level + Building | **All three editors** (Level, Building, Graph), enforced by a test |
| Q6 | What number fields suggest | Default + recent values; nothing; values used in the level | **Default, min, max + last 5 typed** |

Technical choices (Dominus, not design): help ids `<panel>.<field>`; widgets in Luna (`TextField`/`NumberField` hint and suggest, `SuggestList`); one reload registry in `src/game/data_reload.*`; polling watcher (250 ms, 300 ms debounce, no new dependency); per-id hash baseline in run saves with a version bump. The K-M10b design doc may change them with a reason.
