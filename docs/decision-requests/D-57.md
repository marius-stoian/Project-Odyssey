# D-57 K-M10 design decisions: quests and story authoring

Status: **Decided by Dominus (delegated, D-41), 2026-10-05**. Related: D-40, D-41, ADR-019, docs/plans/M10-quests-design.md. The owner may override any row. The beta plan (docs/plans/Beta-test-after-M9.md) planned a beta pass before K-M10; the owner's instruction to continue M10 on 2026-10-05 is read as "go".

| Q | Question | Options | Choice and reasoning |
|---|---|---|---|
| Q1 | How objectives are counted | (a) events since the step started (b) inventory totals | (a): inventory counts break when items are sold or eaten; events are deterministic and testable |
| Q2 | Where events come from | (a) one queue the Game feeds where it already knows the fact (b) the Simulation polls state | (a): no hidden coupling |
| Q3 | Prerequisite language | (a) the shared rule language plus `quest(id)` and `step(id)` (b) a list of ids | (a): ADR-019, one language |
| Q4 | Giver resolution | (a) at run time, `role:<role>` = first living NPC in id order (b) fixed at load | (a): NPCs die and move; id order is deterministic |
| Q5 | How a quest is offered | (a) an extra dialogue choice built from quest data (b) only `quest start` in .dlg | (a), with (b) still possible |
| Q6 | Failed quests | (a) final, debugger can reset (b) retry button | (a): simplest; retry would be a new story |
| Q7 | Tracker | (a) one pinned quest (b) all active | (a): small HUD; the journal lists all |
| Q8 | Marker kinds | `tag:`, `object:`, `npc:`, `place:`, nearest to the hero | the brief's example; `systems.markers` switches them off |
| Q9 | JSON comments | allowed in quest and story event files | Codex US-180; the writer drops them |
| Q10 | Save | quest section in the region save, version bump with migration | Charter rule 8; old saves load with every quest locked or available |
| Q11 | Tutorial migration | `first-day.json` replaces `tutorial.json`; the `Tutorial` class leaves the HUD path | brief section 2 |
| Q12 | Crossroads | one file per event under `story/events/`; the old file is a fallback for one version | no flag day |
| Q13 | Debugger scope | throwaway copy; never writes unless the owner saves | brief section 6 |
| Q14 | Quest hook for NPC actions | deferred: no M10 acceptance criterion asks for it (CI-018) | the M9c action schema keeps its three sources until a story asks for the fourth |
