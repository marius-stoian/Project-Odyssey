# D-52 NPC roles, talk and trade: the owner's answers

Status: **Decided (owner, 2026-10-04)**, in six chat rounds with Dominus. Brief: docs/plans/M9a-npc-roles-brief.md. Codex: v2.9 (M9a, M9b, M9c).

| Q | Question | Owner answer |
|---|---|---|
| Q-01 | Where in the build order | Right after the current milestone (M8c) is finished, before M8d |
| Q-02 | NPC categories | The owner creates, edits, deletes and assigns them in the Editor (they are the NPC Classes, see S-04) |
| Q-03 | Where kind defaults live | One file per kind, `assets/data/npcs/<kind>.json` |
| Q-04 | Attitudes | friendly, neutral, wary, hostile, scared, suspicious, enchanted, lovingly, enviously |
| Q-05 | Attitude changes in play | Yes, through dialogue quality and frequency, gifts, trade, help events, a marriage in the family, being in the same family |
| Q-06 | Factions | No factions: every NPC has its own attitude. A store tracks every NPC's data; up to 100,000 region-loaded NPCs in the end game |
| Q-07 | Placed NPCs in the clan simulation | Yes, full persons (needs, memories, ageing) |
| Q-08 | How allowed actions are set | Both: tags give the defaults, allow and deny lists fine-tune |
| Q-09 | Denied action in the menu | Hidden; a pop-up lists every action of that NPC and what it requires, so the player knows how to unlock it |
| Q-10 | Dialogue per NPC | Every NPC is set by hand in the Editor; it gets a set of default dialogues and actions for its interactions with the Player, other NPC Classes, Animals, the Environment (list to grow later) |
| Q-11 | NPC with no script | No Talk option |
| Q-12 | Talking to hostile NPCs | Yes, but through a separate button: taunt, insult, ask for peace, antagonise, de-escalate; each has gameplay consequences (opinions of the involved entities change by the interaction model) |
| Q-13 | Trade style | Both barter and currency |
| Q-14 | Prices | Supply and demand |
| Q-15 | Reputation gates prices and access | Yes |
| Q-16 | Stock | Limited, restocks daily |
| Q-17 | What traders buy | Their wants at full value, other goods at half |
| Q-18 | Behaviour | Full day and night schedule; NPC Class actions, Quest actions, Custom actions, Event actions; all editable in the Editor |
| Q-19 | NPCs act on each other | Everything (talk, fight, trade, gift, confront) through the same interaction files |
| Q-20 | Editor order | Forms first, the graph editor later (US-172 in M9) |
| Q-21 | Map markers | Colour ring and a small icon |
| Q-22 | Test level cast | 7 NPCs: trader, talker, wary hunter, elder, guard, goblin, deer |
| Q-23 | Which level | A new `assets/levels/npc-test.json`; `valley.json` stays untouched |
| Q-24 | F5 reload | Yes, F5 reloads NPC data |

Follow-up round (same day):

| Q | Question | Owner answer |
|---|---|---|
| S-01 | How to split the larger scope | Three milestones: M9a NPC foundation, M9b Trade economy, M9c NPC life |
| S-02 | Scaling to 100,000 persons | Detail by distance: full simulation near the hero, a coarse daily summary far away; compact per-NPC store; relationships kept only for pairs that met |
