## What the exit review found and fixed
- **A run in play, the Editor, and back to the game read freed memory.** The exit demonstration (below) placed a plant with the Editor while a hero's run was in play; going back to the game restarts the level (`resetPlay` makes a new clan) while the run (`HeroLife`) still pointed at the old clan. AddressSanitizer reported a heap-use-after-free in `RunFlow::buildMantle`. The bug is older than M11 (no earlier test combined a run with the Editor). Fix in `OdysseyGame::resetPlay`: a restart ends the hero's run and closes its screens. Regression test: `X-M11 Restart`.
- One change to an earlier test's data: `assets/levels/npc-test.json` is now level version 7 (US-195 bumped the level format; the round trip of `US-270 Loads clean` writes the current version). Not a change of what the test asserts.
- No test was changed because it was wrong about the requirements.
