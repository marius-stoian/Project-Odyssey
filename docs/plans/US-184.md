# US-184 Quest graph editor: plan and checks

Design: docs/plans/M10-quests-design.md section 8.

## Built
- `GraphEditor::Kind::Quest` (open, create, save, check, Tidy, side panel, toolbar buttons, shared Undo), `src/game/quest_graph.{h,cpp}` (cards, conversion both ways, layout keys), Editor toolbar button Quests.
- Parser fix: a step that failed to read is blamed once, not once for every step that points at it.
- Findings: structural problems from the conversion now; the full quest check (US-187) joins `recheck`.

## Manual checks (run at X-M10)
1. Editor -> Quests: the list shows the quests; open one: cards and wires; drag, zoom, wire a new step in, Tidy.
2. Save: the file and the `.quest.layout.json` are written; F5 not needed (the game reloads); a deliberately wrong goal says `unknown objective` and writes nothing.
3. Ctrl+Z walks back through graph and map edits.
