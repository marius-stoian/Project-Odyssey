# US-185 The tutorial as a quest; story events: plan and checks

Design: docs/plans/M10-quests-design.md section 9. Decisions: D-57 Q11, Q12.

## Built
- `assets/data/quests/first-day.json` replaces the tutorial in the game: New Game with Tutorial on sets the flag `tutorial`; the quest requires it and starts by itself; the elder's box shows the active step (and the hint after 120 s). `Tutorial` is no longer used by the game; `tutorial.json` and the class stay only for the first-version tests (`tests/game/m6_test.cpp`), see CI-019.
- `assets/data/story/events/*.json` (12 files, `order` keeps the old order) replaces `hero/crossroads.json`, which the loader still reads when the folder is missing; new field `trigger` (checked at load, decided by `HeroLife::setEventTrigger`).
- Editor: Events button, `StoryEventEditor` (forms; Save checks with the game's reader, keeps `.bak`).

## Manual checks (run at X-M10)
1. New Game with Tutorial on: the elder box says the gather words; gather, eat, tend in turn; after 2 minutes idle the hint shows; the closing words show at the end. Tutorial off: no box, no quest.
2. Editor -> Events: pick an event, change the title and an option, Save, start a new game: the event reads as saved.
3. Put `"trigger": "flag(x)"` on an event: it never comes up until the note is set.
