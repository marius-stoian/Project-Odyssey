# US-187 Quest validation: plan and checks

Design: docs/plans/M10-quests-design.md section 8.

## Built
- `sim::rules::checkQuest` and `checkQuests` (`src/sim/quest_check.cpp`, declared in `graph_check.h`): unreachable steps, steps that cannot reach END, unknown items, interactions, people, places, kinds and quests, prerequisite cycles by depth-first search.
- `GraphCatalog` gains people, places, kinds and quests; the game fills them (people, places and kinds only for a level with characters).
- The graph editor lists the findings of the open quest, clickable; the game logs the findings of all quests at load.
- A test runs the check on every shipped quest.

## Manual checks (run at X-M10)
1. Add a step nothing leads to in the Quests tab: it is listed with `?`; clicking it selects the card.
2. Write `gather berrys 3`: listed with `!` as an unknown item.
3. Make two quests require each other: the log says `quests need each other: a -> b -> a`.
