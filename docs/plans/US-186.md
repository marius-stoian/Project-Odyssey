# US-186 Play-in-editor debugger: plan and checks

Design: docs/plans/M10-quests-design.md section 7.

## Built
- Luna: keys F10 (`Intent::QuestDebug`) and P (`Intent::PlayHere`).
- Game: `src/game/quest_debug.cpp` (panel, actions, why-not), Play here in `OdysseyGame::update` (Editor mode), `completeQuest` in `builtin_actions.cpp`; `QuestBook::holds`.
- The panel works on the running game (in a Play here session that is a copy of the level, so the files never change); it opens in Debug builds only.

## Manual checks (run at X-M10)
1. Editor, P over the map: the hero stands there; Esc is back in the Editor with the level unchanged.
2. F10: start, step, complete, fail, reset a quest; toggle a flag; add an item; opinion; hour/day/season; To marker. Each shows in the game at once.
3. Select a quest that waits on a flag: Why not? shows `[no]` for the condition, and `[yes]` after the flag is set.
