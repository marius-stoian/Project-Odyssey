# US-232 Camera zoom and UI scale: plan

**Design (D-44, ENV-18).** The game is laid out on a 960 x 540 screen. Two whole-number scales sit on top of it:

- **Camera zoom** (1x or 2x, default 2x, so the world looks as it always did): the camera shows `960 / zoom` x `540 / zoom` world pixels (2x: 15 x 8.4 tiles, 1x: 30 x 17 tiles) around the hero.
- **UI scale** (1x or 2x, default 1x): the interface is laid out in `960 / scale` x `540 / scale` of its own pixels.

**How (Engine).** `luna::engine::ScaledRenderer` wraps the real renderer and turns every draw into a whole-number block, so pixel art and the 5x7 font stay crisp. `OdysseyGame::render` draws the world through one ScaledRenderer (zoom) and the interface through another (UI scale). `Camera::setViewSize` changes the view and keeps its centre. `scaledPointer` turns the pointer into the pixels of each picture; `update` makes a world pointer and a UI pointer before anything reads it, so aiming, right clicks and menus all hit what they show (pointer mapping, US-121).

**Controls.** Settings screen: "Camera zoom" and "UI scale" buttons. In play: the keys + and - (also on the number pad) and the mouse wheel zoom; UI scale stays in Settings. Both are saved in `settings.json` (`cameraZoom`, `uiScale`).

**Tests.** `tests/luna/zoom_test.cpp` (scaled drawing, camera view, pointer at both zooms); `tests/game/aiming_test.cpp` ("US-232 The pointer hits the same world spot at any zoom", "US-232 Zoom keys and the wheel"). Older game tests run at zoom 1x (`setViewScales(1, 1)`) so their world-relative pointer positions stay simple.

**Manual checks (owner's PC, GPU renderer).**
1. Start the game: the world looks as before (zoom 2x). Press `-` or scroll down: 30 x 17 tiles around the hero; `+` or scroll up: back.
2. Settings (Esc): pick UI scale 2x: HUD, hotbar and panels double in size, still crisp; back to 1x.
3. Aim and click at both zooms: the sword and spear go where the cursor is.

Screenshots (GPU renderer, `--screenshot`): `docs/evidence/US-232/zoom-2x.bmp`, `zoom-1x.bmp`, `ui-2x.bmp`.

**Not in this story.** The run screens and editors still use the old fixed layouts; US-233 lays them out for 960 x 540. The Editor ignores zoom (it stays 1x) and uses the UI scale only for its labels.
