# US-183 Journal, tracker and markers: plan and checks

Design: docs/plans/M10-quests-design.md section 6.

## Built
- Luna: key J -> `Intent::Journal` (new intent at the end of the list).
- Game: `MenuTab::Journal` in the Esc menu (J toggles it); `drawQuestTracker`, `drawQuestMarker`, `questMarkerPosition`, `trackedQuest` in `src/game/quest_ui.cpp`; the marker target is refreshed twice a second in `tickQuests`.
- `settings.json` gains `markers` (1 or 0, default 1) with a Settings button pair.

## Manual checks (run at X-M10)
1. With two active, one done and one failed quest, press J: the groups and step texts show; J again closes.
2. Complete a step: the tracker changes at once.
3. A step with `"marker": "npc:elder"`: a gold v over the elder, an arrow at the edge when off screen; Settings -> Quest markers Off hides it.
