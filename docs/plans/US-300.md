# US-300 Field tooltips from help.json: plan and checks

Design: docs/plans/M10b-editor-help-design.md section 2. Decisions: D-58 Q2, Q5, Q7; D-59 Q1 (0.4 s).

## Built
- `luna::engine::FieldHint` (src/luna/engine/ui.*): the tooltip of a field. `TextField` and `NumberField` get `helpId` and `tip`; `drawOverlay` shows the lines (purpose, range, example, broken at 60 letters) after the pointer has rested 8 ticks (0.4 s at 20 ticks a second); moving, leaving or clicking the field hides it. Buttons keep their instant `hint`.
- `EditorHelp` (src/game/editor_help.*): reads `assets/data/editor/help.json` (comments allowed), validates it all or nothing (`help.json:<line>: message`), and gives every field of a panel its id and tooltip. A missing or broken file leaves the Editor without tooltips and names the file and line in the status line.
- Every Editor calls `applyHelp` at the start of its update, so each panel is given its help one tick after it is built. The panels know what they were built as (`classesAreKinds_`, `propertiesForPlant_`, `GraphEditor::panelPrefix_`), so an id never belongs to a panel that changed tabs a moment ago.
- `assets/data/editor/help.json`: 127 entries (all fields of the Level Editor, Building editor, Graph editor and Story events list).
- Docs: "Tooltips and suggestions" in docs/guides/editor.md.

## Technical choices (changes to the design document, with reasons)
- The id of a field is made from its panel and its label (`npc.sword`), not set by hand at each of about 130 call sites. It cannot drift from the screen, the editors need no edit per field, and a reworded label fails the coverage test by name. A hint in brackets is dropped from the id and an indented label gets `sub-`.
- The design counted about 41 fields in three editors; there are 127 in four (the Story events list, added in M10, is the fourth). D-58 Q5 says every field, so all four are covered.
- Range of a number field comes from its own minimum and maximum when the entry has none.
- The tooltip uses 8 ticks because the game runs at 20 ticks a second (Charter: fixed step).

## Tests
- `US-300 Field tooltip` (tests/luna/ui_test.cpp): wait, show, moving restarts, leaving hides, a click hides, no text no tooltip, long lines break.
- tests/game/editor_help_test.cpp: format of the shipped file, ids, hover text from a file with comments, a broken file (status line names `help.json:4`), a missing file, three validator mistakes with lines, coverage (every field of the four editors has an entry and every entry has a field).

## Manual checks (screenshots in docs/evidence/US-300/)
1. Editor, select a placed NPC, rest the pointer on Sword: the box shows purpose, range and example after a short pause.
2. Same on a field of the Building editor (Prefab tab, Cost) and of the graph editor (a line card's says).
3. Break `assets/data/editor/help.json` (delete a quote) in a copy of the data folder: the Editor opens, no tooltips, the status line names the line.
