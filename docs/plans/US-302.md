# US-302 Suggestions on every field: plan and checks

Design: docs/plans/M10b-editor-help-design.md section 4. Decisions: D-58 Q3, Q6; D-59 Q2.

## Built
- `EditorHelp::suggestionsFor(id, min, max)` (src/game/editor_help.*): resolves the entry's `suggest` each time a list opens: `number` (default of the edited kind, min, max, last five typed), `files:<folder>/<glob>` (under the data folder; `*`, `*.ext` or a whole name), `catalog:<name>`, `values:a|b|c`, `none`. `EditorHelp::apply` wires `suggest` (and `listItems` for `"list": true`) on every field that has an entry other than `none`, once per widget, and wraps a number field's `onChange` once to remember what was typed.
- `OdysseyGame::suggestionNames(catalog)` and `suggestionSources()`: the seventeen catalogs of the design, read from the data in use (classes, kinds, partner types, interactions and their fields, light kinds, objects, plants, characters, items, building kinds, prefabs, quests, levels, tags, places, markers). `Editor::numberDefault` gives the kind's HP and sword damage of the selected character.
- `help.json` requires a `suggest` on every entry; the validator names a missing or unknown one with its line. `graph.step.marker` offers `catalog:markers`.
- Luna: a list of words completes the word after the last comma or space (US-301's comma-only rule widened, because several fields take words separated by spaces).
- Docs: "Suggestions (US-301, US-302)" in docs/guides/editor.md lists every source with an example.

## Technical choices
- Sources are functions the game gives the help object (a strategy per catalog), so `EditorHelp` knows no game data types and tests give it their own.
- Fields are wired in `apply` (once per widget), not at each call site, like the tooltips of US-300.
- The Classes field of the acceptance criteria does not exist as a text field (a class is ticked in a list); the list-completion rule is shown on **Allow**, **Deny**, **Does** and **Tags**, and a test completes an item after "trader, " with the class catalog.

## Tests
tests/game/editor_suggest_test.cpp: Text (Script lists the .dlg files starting with "el"), Lists ("trader, " plus "e"), Numbers (wolf: 50, 1, 9999, then the last five), no default (limits only), Fresh (a class saved is offered at once), Catalogs (every catalog), Values and none, Mistakes (no suggest, unknown source), Wired (fields got their lists), Screen. The coverage test of US-300 also fails for an entry that offers values but reached no field. tests/luna/ui_test.cpp: words separated by spaces.
